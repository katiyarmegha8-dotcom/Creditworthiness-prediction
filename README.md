# Credit Scoring Model

## Objective
The objective of this project is to predict an individual's creditworthiness using historical financial data. The model helps determine whether a customer is likely to be a good or bad credit risk.

## Features Used
- Income
- Debt
- Loan Amount
- Credit History
- Payment History
- Number of Credit Accounts
- Age

## Machine Learning Techniques
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC Score

## Workflow
1. Data Collection
2. Data Preprocessing
3. Feature Engineering
4. Model Training
5. Model Evaluation
6. Creditworthiness Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Results
Random Forest achieved the best performance among the tested models with high accuracy and ROC-AUC score.
